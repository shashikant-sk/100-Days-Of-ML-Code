## 2024-05-25 - Informative Image Accessibility in Markdown
**Learning:** Repositories prioritizing visual infographics in Markdown docs often use raw HTML `<img>` tags for alignment and styling but neglect `alt` attributes, making the core content inaccessible to screen readers.
**Action:** Always check high-visibility Markdown files (like `README.md`) for missing `alt` attributes on informative HTML images and add descriptive text to improve accessibility.
