## 2024-05-15 - Missing Alt Text in HTML Image Tags within Markdown
**Learning:** This repository extensively uses HTML `<img>` tags (often wrapped in `<p align="center">`) rather than standard Markdown syntax `![]()` for embedding images and infographics. This pattern can easily slip past standard Markdown linters or accessibility checkers that only scan for `![]()` syntax, leading to missing `alt` attributes and degraded accessibility for screen readers.
**Action:** When auditing or enhancing markdown files in this repository (or similar setups), specifically search for raw HTML `<img>` tags to ensure they include descriptive `alt` text. Consider adding a custom linting rule or a check in the CI/CD pipeline to flag missing `alt` attributes in raw HTML tags within Markdown.
