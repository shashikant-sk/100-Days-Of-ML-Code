## 2024-05-24 - HTML Img Tags in Markdown
**Learning:** This curriculum repository heavily relies on direct HTML `<img>` tags embedded in `.md` files to display large infographics, rather than standard Markdown syntax.
**Action:** When optimizing repositories that are primarily documentation or markdown-based, check for embedded HTML as it represents a valid target for standard web optimizations like `loading="lazy"` which significantly improves load performance on GitHub and Jekyll sites.
