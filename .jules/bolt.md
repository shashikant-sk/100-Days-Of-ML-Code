## 2024-05-24 - Performance: HTML <img> tags in Markdown
**Learning:** This repository is heavily reliant on inline HTML `<img>` tags for displaying large infographics within its Markdown files. Since there are many images and no native application handling lazy loading, these embedded `<img>` tags create a performance bottleneck on page load by fetching all infographics simultaneously.
**Action:** When optimizing performance in Markdown-heavy repositories like this, look for embedded HTML `<img>` tags and add `loading="lazy"` attributes. This simple web optimization drastically improves initial load times by deferring the fetching of off-screen images.
## 2024-05-24 - Performance: GitHub raw URLs and Async Image Decoding
**Learning:** This repository embeds GitHub-hosted images via HTML `<img>` tags inside Markdown files using `github.com/.../blob/...` URLs. This prevents direct image retrieval and causes significant performance overhead by forcing the browser to load GitHub's HTML UI wrapper for every image. Furthermore, these heavy infographics lacked `decoding="async"`, blocking the main thread during image decoding.
**Action:** When working on performance optimization for embedded images in this repository, ensure that `<img>` `src` URLs always point directly to the raw image (e.g., `raw.githubusercontent.com/...`). Also add `decoding="async"` to prevent the browser from blocking the main thread while decoding these large assets.
