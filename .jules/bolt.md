## 2024-05-24 - Markdown Image Optimization
**Learning:** This repository uses raw HTML `<img>` tags for images in Markdown instead of standard `![]()` syntax. This allows for native HTML performance attributes like `loading="lazy"`.
**Action:** When optimizing images in this repo's Markdown files, leverage HTML attributes (like `loading="lazy"`) directly on the `<img>` tags instead of trying to optimize standard markdown image syntax.
